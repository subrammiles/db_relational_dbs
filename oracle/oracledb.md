Oracle Database is officially supported on specific operating systems chosen by Oracle. Ubuntu is not officially supported, which is why installation there requires workarounds.

Below are the main officially supported operating systems.

1. Oracle Linux (Most Recommended)

Oracle’s own Linux distribution.

Fully optimized for Oracle Database

Most tested platform by Oracle

Best performance and compatibility

Versions commonly supported:

Oracle Linux 7

Oracle Linux 8

Oracle Linux 9


| Operating System         | Support Level              |
| ------------------------ | -------------------------- |
| Oracle Linux             | ⭐ Best support             |
| Red Hat Enterprise Linux | Fully supported            |
| SUSE Linux Enterprise    | Supported                  |
| Windows Server           | Supported                  |
| Solaris                  | Supported but less common  |
| Ubuntu                   | ❌ Not officially supported |
